ArcGIS Pro — Apply to Baseline (do this first):
  1. Right-click KDE_Tiger_Baseline_2006_2010 → Symbology → Primary: Classify
  2. Method: Manual Interval (not Natural Breaks — you are entering the recorded break values)
  3. Classes: 5
  4. Click each break value in the histogram and type in your recorded values from Week 5
  5. Set each class colour to hex values above (double-click colour chip)
  6. Layer transparency: 20%
  7. NoData: transparent (no colour)
Apply identical breaks to Current KDE:
  1. The KDE_Classification.lyrx saved in Week 5 already has these breaks
  2. Right-click KDE_Tiger_Current_2018_2022 → Symbology → menu (≡) → Import symbology → select symbology/KDE_Classification.lyrx
  3. Verify breaks match baseline exactly — do not allow ArcGIS to recalculate
Search radius: 20km (selected from 10/20/30km test — best balance at reserve scale). Class breaks from Natural Breaks (Jenks) applied identically to both periods via KDE_Classification.lyrx. Raw density values not directly comparable between periods (908 vs 116 points) — shared breaks ensure visual comparability only.

ArcGIS Pro — Symbology panel:
  1. Right-click HotSpot_Tiger_GiStar → Symbology → Primary: Unique Values
  2. Field: Gi_Bin
  3. For each value: double-click symbol → Properties → Circle marker, set size and colour above
  4. Not Significant (0): set transparency 50% — visually recedes without disappearing
  5. Hot spot sizes increase with confidence (3px → 5px → 6px → 8px) to encode significance visually
Orange-red (hot) / purple (cold) diverging scheme is safe for deuteranopia and protanopia (red-green colourblindness). Avoids the standard ArcGIS red/blue Gi* palette which fails deuteranopia simulation. Verified with Coblis colourblind simulator.
